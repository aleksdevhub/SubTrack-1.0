# 💳 SubTrack

> **SubTrack** — веб-сервис для удобного контроля, учета и аналитики ваших регулярных подписок. Отслеживайте активные сервисы, контролируйте даты списаний и наглядно анализируйте расходы за месяц и год в одном месте.

## ✨ Основной функционал

- **📊 Дашборд и общая статистика:**
  - Общий баланс трат и список активных сервисов.
  - Карточки с ближайшими списаниями (дата, название, сумма).
  - Группировка подписок по категориям (Стриминг, Музыка, Софт и др.).

- **📉 Глубокая аналитика трат:**
  - График динамики расходов по месяцам.
  - Прогнозирование общих расходов на год вперед.
  - Расчет средней стоимости подписки и определение наиболее затратных категорий.

- **⚙️ Управление подписками:**
  - Удобное добавление сервиса с настройкой цикла оплаты (месяц/год), даты и привязанной карты.
  - Персональные страницы для каждой подписки с детальной историей платежей.
  - Редактирование параметров или отмена подписки в пару кликов.

- **🔔 Уведомления и Безопасность:**
  - Напоминания за 2–3 дня до предстоящего автоматического списания.
  - Управление данными аккаунта, смена пароля и настройка профиля.
